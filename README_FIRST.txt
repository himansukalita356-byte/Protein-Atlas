PROTEIN ATLAS - HOW TO RUN (Windows)

1. Right-click the zip -> "Extract All..." (do NOT run it from inside the zip).
2. Open the extracted folder "protein-sequence-analyzer".
3. Double-click START_HERE.bat
4. Chrome opens at http://127.0.0.1:8000/  (the first start installs packages: 1-2 minutes)

Needs: Python 3.10+ (python.org, tick "Add to PATH") and an internet connection
(protein data comes live from UniProt, PROSITE, RCSB PDB, AlphaFold DB and SWISS-MODEL).

To check everything works on YOUR machine: open the site, click "Run self-test" at the bottom
of any page, then "Run all checks".

To stop: close the black window.
