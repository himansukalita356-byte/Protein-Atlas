# Protein Atlas — Protein Sequence Analyzer

A scientific protein analyzer with three faces that share **one** calculation engine:

* **Protein Atlas** — the interactive web app (this is what you launch)
* a **FastAPI** service (`api.py`)
* the original **command-line** analyzer (`protein_analyzer.py`)

## Launch (Windows, Chrome)

1. Right-click the zip → **Extract All**.
2. Double-click **`START_HERE.bat`**.
3. Chrome opens at <http://127.0.0.1:8000/>.

Manual launch (any OS): `pip install -r requirements.txt` then `uvicorn api:app` and open
<http://127.0.0.1:8000/>. Interactive API docs: <http://127.0.0.1:8000/docs>.

First run only: the PROSITE database (~25 MB) and the complete dataset statistics download in the
background and are cached in `.atlas_cache/`. The site is usable immediately; pages tell you exactly
what is still loading.

## What it does

| Area | Highlights |
|---|---|
| **Discover** | Live UniProt search; **server-side pagination** (First · Previous · Page X of Y · Next · Last, jump-to-page, page size); search and page live in the URL |
| **Protein page** | Overview (most/least abundant residue, chemical families), Physicochemical (mass breakdown that reconciles with the molecular weight, pI, charge curve), Sequence Features (custom pattern search, PROSITE motifs, repeats), Amino Acids (all 20, position finder, enrichment vs dataset), Hydropathy (zoom/pan, membrane bands), Function Scan, Full Sequence, Export |
| **3D structures** | Resolution pipeline **PDB → AlphaFold DB → SWISS-MODEL → ESMFold**; “no AlphaFold model” never hides an experimental structure; every database's status is reported; full-screen viewer with rotate / zoom / pan, cartoon · stick · ball & stick · spacefill · surface, colouring by N→C / chain / structure / confidence, residue inspector, a deep-zoom *detail lens* that reveals atoms, bonds and residue labels |
| **Sequence Lab / Pattern Lab** | Paste any sequence; same engine and same tabs as UniProt proteins |
| **Compare** | Properties, composition, k-mer similarity (k validated with a precise message), similarity-vs-k and dot plot |
| **Reference** | The 20 amino acids: formula, masses, pKa (free amino acid and EMBOSS), pI, hydropathy, hydrogen-bond roles, SMILES, PubChem link and an interactive **3D model with atoms and bonds** that works offline |
| **Dataset** | Complete statistics for a whole UniProt dataset (streamed once, cached, rebuilt on demand) with distributions, frequencies, validation and CSV |
| **Export** | FASTA, composition / mass / hydropathy / PROSITE CSV, JSON, text report |

See [`docs/FEATURE_MAP.md`](docs/FEATURE_MAP.md) for the complete backend → frontend → visualization map.

### Scrolling and charts

The mouse wheel scrolls the page everywhere **except** while the pointer is over a chart (zooms it) or the
3D viewer (zooms the molecule). Each chart has a *Wheel zoom* switch to release the wheel, plus + / − / Reset
buttons; drag pans and double-click resets.

### Navigation

Routing is URL based: Discover → Protein → tab → 3D viewer are all history entries, so browser Back/Forward
(and the in-page Back link) return to the previous state, including the search text and page number.

## Verify it on your machine

Open the site and click **Run self-test** in the footer (`#/selftest`), then **Run all checks**. It exercises
pagination, values, the pattern table, PROSITE, chart wheel behaviour, 3D data, the amino-acid models, Sequence Lab,
comparison validation, dataset statistics, back/forward and scans every page for placeholder text.

Automated tests (no internet needed): `pip install -r requirements-dev.txt` then `python -m pytest`.

## Architecture

```
frontend/js/*.js            browser app (no build step)
api.py                      routes + error translation only
atlas_services.py           UniProt paging, structures, PROSITE, dataset statistics (HTTP, caching)
atlas_engine.py             the one validated sequence-analysis engine
atlas_aminoacids.py         offline 3D models + free-amino-acid constants
protein_analyzer.py         original CLI; constants and PROSITE helpers are shared
data/amino_acid_structures.json   geometries generated by tools/build_amino_acid_structures.py
```

Configuration (environment variables): `UNIPROT_API_BASE_URL`, `PROSITE_URL`, `UNIPROT_QUERY`,
`ATLAS_CACHE_DIR`, `ATLAS_PREBUILD_STATS=0` (skip the background statistics build), `CORS_ALLOW_ORIGINS`.

## Scientific conventions

* Molecular weight: average masses; sum of residue masses + one water.
* pI / net charge: EMBOSS pKa set, Henderson–Hasselbalch, solved by bisection.
* Hydropathy: Kyte–Doolittle; membrane-like segments = 19-residue window averaging above 1.6 (heuristic).
* k-mer similarity: Jaccard index of distinct k-mers, k limited to 1–20 and to the shorter sequence.
  A similarity of 0 for long words between unrelated proteins is a genuine result, and the page says so.
* Amino-acid 3D models are a clean, validated *model* of the neutral free amino acid (bond lengths, angles, planarity,
  clashes and L-stereochemistry are checked in the tests) — not an experimental structure.
